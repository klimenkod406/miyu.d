# Miyu Frontend

Frontend для стримингового сервиса Miyu.

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Структура

```
src/
├── components/  # UI компоненты
├── pages/     # Страницы
├── types/     # TypeScript типы
├── hooks/     # Хуки
├── api/       # API запросы
└── utils/    # Утилиты
```
