# Данные для входа в подготовленные аккаунты

## Общая информация

- Все автоматически созданные **artist-аккаунты** используют общий пароль:

```text
artist123
```

- Базовый **admin-аккаунт** использует пароль:

```text
admin123
```

- Для созданных артистов логин выполняется по **email**.
- `username` у каждого артиста совпадает с его сценическим именем.

## Базовые аккаунты

### Admin

- Email: `admin@miyu.ru`
- Username: `MiYu Admin`
- Password: `admin123`

### Первый artist-аккаунт

- Email: `artist@miyu.ru`
- Username: `MiYu Artist`
- Password: `artist123`

## Сгенерированные artist-аккаунты

artist123
