## Примечания

1. **Поиск** — универсальный, одна страница `/search` с табами: Все / Треки / Артисты / Альбомы / Плейлисты

2. **Оплата (ЮKassa)** — имитация:
   - Подписки (ежемесячные: Free / Pro / Ultra)
   - Разовые платежи (билеты, донаты)
   - Тестовый режим без реальных списаний

3. **Авторизация** — JWT + refresh tokens
